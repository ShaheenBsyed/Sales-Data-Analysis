# 📊 Sales Data Analysis using Python


## 📌 Overview

This project analyzes retail sales data using Python to uncover
business insights related to sales performance, profitability,
regional trends, and sales targets.

The objective is to demonstrate data analysis skills by converting
raw transactional data into actionable business recommendations.

## 🎯 Business Questions

✔ Which product category generates the highest revenue?

✔ Which category is the most profitable?

✔ Are furniture sales targets improving over time?

✔ Which states perform the best and worst?

✔ What recommendations can improve business growth?
